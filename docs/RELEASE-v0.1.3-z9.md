# EasyDesk Einform v0.1.3-z9

本次发布加入按小时生成和刷新、图片回收站清空、独立命令通道与 Easyupdate 接入。

## 本次改动

- 图片预览加入「一键清除回收站」，仅永久清除已删除且属于本项目索引的 PNG，保留有效缓存与设备选用图片。
- 自动更新间隔以小时输入，支持固定间隔和自适应提前更新。开启自动刷新 APP 后，到期重新生成 PNG 并下发对应图片；普通取图请求不会推迟计划。失败保留原图并重试。
- 在线终端通过独立长轮询及时接收命令，刷新、强制重绘、维护页和重启不等待心跳。绘制过程收到的命令排队执行；完成后持久化去重并 ACK。
- 手动快照与维护模式优先于并发的旧自动刷新命令。同一设备的多次强制生成按顺序执行。
- APP 接入 Easyupdate API v1，设置中可配置更新地址、检查新版本、下载并调用系统安装器。检查完整长度、SHA-256、应用包名、版本、相同签名与 minSdk；拒绝跨源下载和不完整 APK。

## 使用

服务部署在 `192.168.95.55:19900`，登录后进入「图片预览 → 自动生成与缓存期限」设置小时数。打开「启用服务器自动更新 PNG」和「生成新 PNG 后自动刷新 APP 内容」。要严格按所填间隔更新，关闭自适应提前更新。设备选择「自动图片」参与定时刷新；手动选用的缓存图片继续保持至到期或主动切回自动模式。

升级保留服务器原运行配置；新开关默认关闭，避免已有终端在升级时突然开始强制清屏。手动命令始终独立于这个开关。

更新服务默认为 `http://192.168.95.55:19910`。进入 APP 设置，确认该地址从终端网络可达，再点击「检查 APP 更新」。更新会打开系统安装器，由用户完成安装；受限 Z9 ROM 的特殊安装方式见 [终端说明](../agent/README.md)。旧版 0.1.2 尚未接入 Easyupdate，首次安装本版仍需手动安装 APK，后续版本即可使用 APP 内更新入口。

Docker 部署步骤见 [Docker 文档](DOCKER.md)，接口见 [API 协议](API.md)，小时设置与快照行为见 [图片管理](IMAGES.md)。Mock 为测试天气；真实天气仍需配置和风天气 API Host / Key。
