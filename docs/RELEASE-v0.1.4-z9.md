# EasyDesk Einform v0.1.4-z9

修复 Easyupdate 在局域网转发地址下的下载兼容问题。终端配置 `192.168.3.32:19910` 时，服务器可能在公告中返回全局地址 `192.168.95.55:19910`；此前客户端将这种情况拒绝为异源地址。

客户端现在严格验证公告 URL 的协议、包名和版本下载路径，实际请求始终使用终端配置的服务根地址。不会连接公告中的其他主机；重定向、错误路径、降级及重复版本仍被拒绝。完整长度、SHA-256、包名、签名及最低 Android 版本校验保留。

APK 为 Android 4.4 / API 19，versionCode 5，沿用已有应用签名和设置。服务器程序、Docker 镜像、19900 端口及 Easyupdate 全局配置保持原样；本次只需更新终端 APK。

下载包含 `EasyDesk-Einform-Z9-v0.1.4-z9.apk`、完整源码 ZIP、本发布说明和 SHA256SUMS。构建与实机验证记录见 [终端验收](../agent/VERIFY.md)，受限 ROM 的安装方式见 [终端说明](../agent/README.md)。此前 v0.1.3-z9 发布资产保留。

APK SHA-256：`7e8953ae7b63edd1494b4d61822428c64616f25b125ed9e09693c82702261789`。

API19 ARM 模拟器已验证转发地址归一和完整 APK 校验，真实 Z9 已安装本版，显示、重绘与设置保留验证通过。服务器 19910 服务正常；Z9 经 `192.168.3.32:19910` 转发仍在收到 HTTP 响应前断开，更新联网验收待转发修正。实机系统安装器更新、可听声音与墨水屏残影仍需现场验证。
